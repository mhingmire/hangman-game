# Hangman Game

Just your regular hangman game, built using **Tkinter**, with fun categories, a timer, and a scoreboard. enjoy playing!  

---

## Features
- Choose from **countries, f1, animated disney movies, desserts**  
- **Timer** for each round (90 seconds)  
- **Scoreboard** showing wins and losses  
- Shows hangman drawing that updates with wrong guesses  
- **Keyboard Support** and clickable letter buttons  
- **Play Again** option to reset the game  

---

## How to Run
1. Make sure you have **python** installed  
2. Clone or download this repository  
```bash
git clone <your-repo-link>
cd hangman
```
3. Run the game
```bash
python hangman_gui.py
```
